# Cloud-Workload-Prediction
Cloud Workload Prediction Using Long-Short Term Memory Algorithm. 
To Delves into the dynamic realm of edge computing, focusing on resource management in the context of cross-camera video analytics.
A new service is developed within a Hybrid cloud model to manage workloads across both on-premise and off-premise (Cloud) infrastructures.
The proposed solution uses a Long-Short Term Memory (LSTM) model to improve prediction accuracy while reducing inference overhead.
